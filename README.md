# Awesome Arcade

Configuración personalizada de AwesomeWM para Arch Linux.

## Características

- Barra personalizada.
- Escritorios con temática de Pac-Man.
- Fantasmas de diferentes colores.
- Indicadores visuales para escritorios vacíos y ocupados.
- Configuración modular mediante `rc.lua` y `bar.lua`.

## Estructura

- `rc.lua`: configuración principal.
- `bar.lua`: barra y lista de escritorios.
- `icons/pacman/`: recursos gráficos.

## Instalación

1. Haz una copia de seguridad de tu configuración actual de AwesomeWM.
2. Copia los archivos de este repositorio a `~/.config/awesome/`, respetando la estructura de carpetas.
3. Valida la configuración con `awesome -k -c ~/.config/awesome/rc.lua`.
4. Recarga AwesomeWM con `Ctrl + R`.

**Nota:** pueden ser necesarios otros módulos o dependencias según la configuración de cada equipo.
